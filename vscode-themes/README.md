# Greengold Themes

Green color themes for VS Code, with gold accents.

- **Greengold Dark**: deep forest-green background (`#0b100d`), mint and gold highlights.
- **Greengold Light**: soft sage background, dark green text, readable contrast.

Both themes work with every language. They also carry full semantic highlighting and
extra polish for [Greengold](https://greengoldlang.com/) (`.gg`) files.

## Install

Open the Extensions view (`Ctrl+Shift+X`), search for **Greengold Themes**, install, then pick
**Preferences: Color Theme** (`Ctrl+K Ctrl+T`) and choose *Greengold Dark* or *Greengold Light*.

## Greengold language support

For syntax highlighting, LSP, debugging and the Test Explorer for `.gg` files, install
[Greengold Language Support](https://marketplace.visualstudio.com/items?itemName=greengoldlang.greengold-vscode).
It bundles these same themes.
