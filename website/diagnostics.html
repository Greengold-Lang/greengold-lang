Reading the document

The rule for tools is short: apply a fix only when its applicability is safe or likely and verified is true. Here, two fixes meet that bar and one is manual.

code · rule

A stable code (GG0301) and a rule name. gg explain GG0301 prints the long form.

span · labels

Where the error is, plus labels for the definition, the move, and the parameter that caused it.

details

callee and parameter name the signature that moved the value.

fixes

Each fix has edits, an applicability (safe, likely, manual), and verified.

verified

The compiler applied the edit to a copy, re-checked it, and the diagnostic went away.

manual

A hint, not an edit. A person or a model has to decide what the program should do.
