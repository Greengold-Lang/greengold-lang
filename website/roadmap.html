Roadmap

Version 0.21.0. The compiler is written in Python and emits LLVM IR through llvmlite. Prebuilt downloads are on the GitHub releases page.

In 0.3.0 shipped

  • LLVM is the only backend; the C99 backend is removed
  • var removed; variables are mutable, fixed is inferred
  • Inlay hints for inferred fixed in the language server
  • Parameter modes inferred for heap values from the body
  • for x in xs: lends elements when the body changes x
  • Closures, and owned closures Fn(A) -> R
  • .clone() and reference-counted Shared[T]
  • consume self methods
  • HashMap and HashSet with heap keys and values
  • List insert, remove, swap, swap_remove
  • test blocks, require, and gg test --json
  • Borrowed str views are tracked against their owner

In 0.3.1 shipped

  • Control-flow borrow liveness (non-lexical borrows) across branches and loops
  • Inter-procedural view-flow summaries and fn drop(self: lend Self) destructors
  • Generic bodies checked against their bounds (Copy, Key, features) at declaration
  • dyn Feature for dynamic dispatch through owned feature values
  • Slices []T stored in variables and structs, and returned from functions
  • Capturing Thread.spawn, inferred send, Arc[T], and blocking Queue[T]
  • gg api --lock and --check for semver-checked inferred public APIs
  • Normative spec, conformance suite, and edition = "2026" in gg.toml

In 0.3.2 shipped

  • Hardware atomic intrinsics with memory orderings and lock-free Atomic[T]
  • static globals, constant array/struct literals, and volatile_read / volatile_write
  • union, packed struct, align(N) struct, and inline asm[T]
  • SIMD vector types (f32x4, i32x8, u8x16, ...) lowered to LLVM vectors
  • allocator alloc, resize, free for a custom or --no-std heap
  • std.net TCP sockets, std.io File streams, target_os(), and weak extern

In 0.3.3 shipped

  • gg build -g emits DWARF debug info for gdb and lldb
  • Git and registry dependencies, gg.lock, and gg fetch / update / publish
  • Cross-compilation (--target, gg targets), including wasm32 and cortex-m4
  • C++ interop with gg bindgen --cpp and [native] C/C++ sources in gg.toml
  • Faster gg check and gg build via non-recursive AST walks and pickle snapshots
  • := removed in favor of =, and VS Code extension with gg fix and debugging

In 0.4.x shipped

  • Installers for Windows, Linux, and macOS that need no Python, and a Windows setup program
  • gg update replaces the installed compiler with the newest release; gg update --deps re-resolves dependencies
  • Prebuilt gg for Windows x64, Linux x64 and arm64, and macOS arm64, with Zig inside for linking
  • VS Code extension runs the installed gg; the .vsix is part of each release

In 0.5.0 shipped

  • Browser playground: live diagnostics, checked fixes, and Run, with the compiler running in your browser
  • wasm32-wasi target: print, strings, List, and HashMap in WebAssembly
  • gg doctor, gg repl, gg run -e, and gg new --template

Next planned

  • An Intel Mac build (needs an llvmlite wheel for that platform)
  • Freezing the 2026 edition for 1.0

Self-hosting paused

  • The lexer is written in Greengold and checked against the Python lexer
  • The parser, type checker, and code generator stay in Python while the language settles

Not in the language today, by design: lifetime names and written Send/Share bounds (thread safety is inferred on send parameters). See the rejected forms.
