Why Greengold

Why this shape

Greengold keeps one spelling for each construct and puts ownership where you can see it, so a person and a language model are reading the same program.

01

One way to write each construct

The spec gives one example per feature and a list of forms the compiler rejects. The diagnostic names the rule instead of guessing what you meant, so code written by a person, a teammate, or a language model all looks the same.

else if→elif// note→# notef(consume x)→f(x)fn T.m()→impl T:var x = 1→x = 1
Rejected forms
02

Ownership is three words

read, lend, and consume are written on the parameter. The call stays f(x). For a heap value with no written mode, the compiler reads the body and picks the mode for you — and the caller sees it.

Parameter modes
03

Mutable by default, fixed by inference

Variables can change. A variable that nothing changes is treated as fixed, so writing the word only adds a guarantee. Lending or assigning a fixed value is an error. Your editor shows the inferred fixed as an inlay hint, so you see it without typing it.

Bindings
04

No lifetime syntax

A stored read or lend is tied to the variable it came from. When a function returns a reference and more than one parameter could be its origin, you name it with tied to — a parameter name, not a lifetime variable.

References
05

Failures are loud

Integer +, -, and * trap when the result does not fit. Division by zero and bad shifts trap. Indexing is bounds-checked. All of it stays on in --release. When you want wrapping, you say so: overflow: wrap, a wrapping: block, or a wrapping_add b.

Numbers
06

Diagnostics carry a checked fix

gg check --json returns a code, a rule, a message, a span, labels, and fixes. verified means the compiler applied that edit to a copy and the diagnostic went away. Apply a fix when it is safe or likely and verified.

A real GG0301 document
07

A library you can query

gg api --json lists every public symbol with its module, name, kind, signature, and description. Read a signature from the catalog instead of guessing a parameter mode.
